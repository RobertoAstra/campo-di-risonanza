# Il Campo di Risonanza / The Resonance Field

This repository hosts the public documentation page for the book project  
**Il Campo di Risonanza / The Resonance Field**.

The project documents a long-term collaboration between a human author and an artificial intelligence,
based on authentic interactions and a clear separation between narrative and technical registers.

👉 Official project page:  
https://robertoastra.github.io/campo-di-risonanza/

---

## Project status

- Book I published (Italian and English editions)
- Book II and Book III in development
- Scientific treatise in progress

---

This repository is intentionally minimal.  
No source code, no discussions, no promotional material.

It exists solely to provide a stable, public reference.
